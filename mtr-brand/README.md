# MTR — podoba modela

Znak: **pas negotovosti**. Levo izmerjena črta postaje (bela), pri piki »zdaj« se začne napoved (zelena),
ki se razpira v pas P10–P90 (notranji pas je ožji, zunanji širši). Znak je isti graf, kot ga model riše na zavihku.

| Žeton | Vrednost | Raba |
|---|---|---|
| podlaga | `#06241b` | ozadje znaka |
| znamka | `#34d399` | znak, značka (ne v grafu: ne prestane testa svetlosti) |
| napoved | `#059669` / `#047857` | serija MTR v grafu (temna/svetla tema) |
| primerjava | `#a855f7` / `#6d28d9` | Open-Meteo v grafu |
| meritev | `#e8edf8` / `#0a1628` | izmerjeno |

Napisano je »MTR«, podnaslov »Meteorec · model za dno doline«. Mini različica (16 px) isti znak brez zunanjega pasu.
